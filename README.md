# tomato.nyc

A fresh slice of the internet 🍅

## Description

Simple landing page featuring a tomato emoji on a vibrant tomato-red background.

## Features

- Best-practice HTML5 with proper meta tags
- SEO optimized with Open Graph and Twitter Card support
- Responsive design
- Centered tomato emoji
- Favicon using SVG data URI

## Development

Open `index.html` in your browser to view the page.

## Deployment

This is a static site that can be deployed to any static hosting service (GitHub Pages, Netlify, Vercel, etc.).
